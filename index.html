D6 dice rolls

Roll a fair six-sided die at least 100 times. Record each result as a single digit 1–6, in order. Use the keypad to log rolls, or paste a long string. Spaces and line breaks are ignored. More rolls add more entropy; aim for 24 words by reaching 256 raw bits (usually about 155 rolls).

Source 02

Coin flips

Mapping Heads = 1, Tails = 0

Flip a fair coin at least 256 times. Record H for heads (1) and T for tails (0), in order — or paste a raw 1/0 string directly. Exactly 256 flips give 256 bits and a 24-word seed. Extra flips are handled like Ian Coleman's tool: the leading excess bits are dropped so the raw string is a multiple of 32 bits.

Put them in a ziplock bag or opaque container and shake them up thoroughly — that mixing is what makes the draw random. Field notes

How the math works

Why 100 dice rolls is not the same as 256 coin flips here

Ian Coleman's BIP39 tool converts dice to bits with a biased shortcut: rolls 1–4 become 2 bits, rolls 5–6 become 1 bit (after mapping 6→0). That averages about 1.66 bits per roll, so 100 rolls give roughly 166 bits, not 256. This tool uses that exact mapping so your dice log is reproducible in Ian Coleman's tool. To reach a 24-word seed (256 bits), keep rolling until the raw-bit counter reads at least 256 — usually around 155 rolls.

If you want maximum uniformity, prefer 256 coin flips or the 23-word hat method instead.

How the 23-word hat method completes the phrase

Each BIP39 word is an 11-bit index. 23 words give 253 bits. BIP39 needs 256 bits, so the last 3 bits are supplied by the selector above (default 000). The checksum is the first 8 bits of SHA-256(entropy), appended to make 264 bits, which split into 24 words. The 24th word therefore contains the last 3 entropy bits plus the 8 checksum bits.

Can I reproduce this in Ian Coleman's BIP39 tool?

Dice: paste the exact Used roll log into the Entropy field, select Dice [1-6] (NOT Base 6 [0-5], NOT Base 10, NOT Hex), and set Mnemonic Length to Use Raw Entropy (3 words per 32 bits). Coins: paste the displayed 0/1 string into the Entropy field, select Binary [0-1], and use Use Raw Entropy. Hat: paste the final 24-word phrase into the Mnemonic field — it should validate.

Do this on the same offline machine, not online.

What does "sensitive, but not secret" mean?

A BIP39 seed phrase is secret and can spend real funds. Treat it like cash. An xpub is merely sensitive.
